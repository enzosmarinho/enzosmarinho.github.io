How I work

  • Cut for the ear first, then make the picture hold up (cutaways, J- and L-cuts across a tightened answer).
  • Every export is re-transcribed and compared with the edit, so no word is clipped.
  • Loudness and true peak measured on every delivery; masters in the format you ask for.
  • A short note with each edit: what came out, why, and what stayed on purpose.
  • DaVinci Resolve and FFmpeg; motion graphics built in code (HyperFrames/GSAP), frame-accurate to the voice.
  • Happy to start with a paid test on your footage.
